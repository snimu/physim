# Apparatus schematics

Generated by `scripts/render_apparatus_figure.py` using the native
`physim.devices.lattice_offsets` geometry and `INJ_SIGMA` source width.
These are explanatory schematics of `centered-pulse-v2`, not observations from
a simulated world. Device orientation, spacing and displacement are illustrative.
Mobile variants stack the same panels without changing their meaning.
The current page no longer shows them; its experiment section uses the BF lab view in
`../bf-thread/bf-apparatus.png`.

From the repository root:

```sh
PYTHONPATH=environments/physim:packages/blobkit python scripts/render_apparatus_figure.py
```

Requires the development Python environment with NumPy, SciPy and Matplotlib.
No world simulation or model call is performed.

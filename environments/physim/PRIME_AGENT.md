# Prime Agent integration

Physim uses the native Verifiers `prime-agent` harness. Its configuration and setup are maintained with the [environment package](https://github.com/swpo/residency-environments/blob/codex/physim/environments/physim/PRIME_AGENT.md).

Install this workspace with `uv sync --locked`; see [DEVELOPMENT.md](../../DEVELOPMENT.md) for dependency updates.

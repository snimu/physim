# Prime Agent integration

Physim uses the native Verifiers `prime-agent` harness. Its configuration and setup are maintained with the [environment package](https://github.com/swpo/residency-environments/blob/a124e9bdd9bc3dde9866153207658a64e98f82e8/environments/physim/PRIME_AGENT.md).

Install this workspace with `uv sync --locked`; see [DEVELOPMENT.md](../../DEVELOPMENT.md) for dependency updates.

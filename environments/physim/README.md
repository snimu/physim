# Physim environment source

The environment is maintained in the [residency repository](https://github.com/swpo/residency-environments/tree/codex/physim/environments/physim). This directory contains documentation links only; it is not a Python package.

Run `uv sync --locked` from the repository root to install the revision pinned in `pyproject.toml` and `uv.lock`, together with the editable local Blobkit package.

See [the upstream environment instructions](https://github.com/swpo/residency-environments/blob/codex/physim/environments/physim/README.md) for runtime setup and evaluation, and [the development guide](../../DEVELOPMENT.md) for changing dependencies or testing both packages together.
